## ¿Qué es GoHealthy?

**GoHealthy** es una plataforma web que conecta a nutriólogos con sus pacientes en un solo espacio digital. Permite llevar un seguimiento continuo y estructurado de la alimentación, el ejercicio y la evolución física del usuario, eliminando la dependencia de formatos en papel, hojas de cálculo aisladas o mensajes dispersos por WhatsApp.

> *La mejor organización para el profesional.*  
> *El mejor seguimiento para el paciente.*

## Tecnologías Utilizadas

### Front-End
* **React + React Router:** Biblioteca principal para interfaces de usuario reactivas y gestión de rutas del lado del cliente.
* **Vite:** Herramienta de empaquetado y entorno de desarrollo rápido (*bundler*).
* **Tailwind CSS:** Framework de estilos utilitarios para diseño responsivo y moderno.
* **TanStack Query:** Gestión de estado asíncrono, caché y sincronización de datos con el servidor.
* **Zustand:** Manejo del estado global de la aplicación.
* **React Hook Form + Zod:** Control de formularios de alto rendimiento y validación de esquemas tipados.
* **Recharts:** Biblioteca para la visualización de datos y gráficos interactivos.

### Back-End *(En proceso de definición)*
* **Node.js + Express:** Entorno de ejecución y framework para la construcción de la API REST.
* **Mongoose:** Modelado de objetos (ODM) para interactuar con la base de datos MongoDB.
* **JWT (JSON Web Tokens):** Manejo de autenticación y autorización segura basada en sesiones con tokens.
